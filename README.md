# The-Meridian-Pivot

A 1-week industry working simulation repository for Northstar Retail Co. (Sprint 2).

## Project Overview
This repository contains the live inventory sync service, support tool API endpoints, and sprint assignment deliverables for the Meridian Pivot simulation.

### Repository Structure
- `app.py`: Main Flask application entry point.
- `routes.py`: API routes for deflection stats, orders, returns, and inventory search.
- `db.py`: Data layer for reading JSON datasets (`data/`).
- `solo_recon_graphql/`: Day 1-2 Solo Recon GraphQL mini-prototype and Learning & Blocker Journal.
- `CHARTER.md`: Team working agreement and anti-black-box rules.
- `GOLIVE_READINESS.md`: Deployment readiness checklist.
